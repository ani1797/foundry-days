# Deployment Readiness Checklist

- [ ] Success criteria defined and agreed with stakeholders
- [ ] Test cases cover primary and edge-case task flows
- [ ] Failure handling / fallback behavior defined (e.g., tool errors, missing knowledge)
- [ ] Versioning strategy in place for prompts, tools, and model changes
- [ ] Release gate: minimum evaluation score met (see Day 3 evaluation metrics)
- [ ] Agent identity provisioned with least-privilege access (built on Day 1 landing zone)
- [ ] Rollback plan documented
