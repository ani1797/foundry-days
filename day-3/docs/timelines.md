# Day 3 — Timeline: Evaluations and FinOps (incl. Agent Observability)

**Format:** Lecture + framework walkthrough (metrics, dashboards, review cadence), 2 hours.
Combines agent observability with dedicated evaluations and FinOps content: observing how the Day 2 agent operates in production, evaluation workflows, and operational cost insights.

| Time | Block | Covers |
|------|-------|--------|
| 0:00–0:10 | Opening & Recap | Agent lifecycle recap (Day 2's deployed agent), operational success criteria |
| 0:10–0:30 | Observability Model | Telemetry, traces, evaluations, quality indicators, cost signals, user feedback |
| 0:30–1:05 | Monitoring & Evaluation Demonstration | Follow agent interactions, inspect signals, evaluation metrics (groundedness, relevance, fluency, coherence), quality gates, red teaming, root-cause analysis |
| 1:05–1:30 | Operational Response & FinOps | Alert thresholds, triage process, regression detection, continuous evaluation, token-based cost accounting, budget/cost management for agentic workloads |
| 1:30–1:50 | Guided Planning Activity | Participants build an observability scorecard: signal ownership, thresholds, review cadence, cost dashboard |
| 1:50–2:00 | Wrap-up | Connect observability/evaluation outputs to Day 4 governance decisions |
