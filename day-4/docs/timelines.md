# Day 4 — Timeline: Agent Governance and Security

**Format:** Lecture + control-map workshop, 2 hours, supported by the `Azure AI Foundry Governance.PPTX` deck.

| Time | Block | Covers |
|------|-------|--------|
| 0:00–0:10 | Opening & Risk Framing | Risks of agent autonomy, tool-usage risks, data-access risks |
| 0:10–0:35 | Governance Operating Model | Roles and responsibilities, use-case intake, risk classification, approval models, lifecycle management |
| 0:35–1:05 | Security Design | Least privilege, identity, data protection, network boundaries, secrets management, environment isolation |
| 1:05–1:30 | Trust and Assurance | Evaluation gates, human oversight, audit evidence, policy enforcement, change management |
| 1:30–1:50 | Control Mapping Activity | Participants map risks to controls, identify owners, define evidence requirements |
| 1:50–2:00 | Wrap-up | Review the minimum governance package; preview Day 5 |

**Note:** deep security topics (Agent 365, OBO, Foundry control-plane security) are out of scope here too — candidates for a future dedicated security session (TBD).
