# Minimum Governance Package Checklist

- [ ] Use-case intake form completed and risk-classified
- [ ] Approval obtained from designated risk owner
- [ ] Identity/access reviewed against least privilege (Day 1 foundation)
- [ ] Evaluation gate results attached (Day 3 signals)
- [ ] Audit logging enabled and evidence path documented
- [ ] Change-management process defined for prompt/tool/model updates
- [ ] Control map reviewed and signed off (see governance-control-map.md)
