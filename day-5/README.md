# Day 5 — Microsoft IQ

**Date:** TBD (proposed 5th in series, targeting February)
**Series:** [FSI Foundry Day Series](../README.md) · Previous: [day-4](../day-4/README.md) · Next: [day-6](../day-6/README.md)

## What

Connecting knowledge, context, and intelligence to agent experiences — grounding and retrieval across enterprise data sources, applied within the access-control/governance model established in Day 4.

## Why

FSI agents are only as useful as the knowledge they can safely and accurately access. This session shows how to ground agents in enterprise data while respecting governance boundaries.

**Key concepts:** Microsoft IQ (organizational knowledge, context, relationships, permission-aware intelligence), agentic retrieval, knowledge bases, grounding quality/freshness/ownership, Model Context Protocol (MCP), cross-source data access patterns.

## Audience

Primary: Data & Knowledge Management teams, Application Developers, Enterprise Architects.
Also relevant to: Business/Domain SMEs who own the enterprise data sources being grounded, Governance/Risk stakeholders validating data-access compliance.

## Prerequisites

- Completion of [Day 4](../day-4/README.md): grounding here must respect the access-control/governance model established there.
- Basic understanding of common enterprise data sources (e.g., SharePoint, Fabric, web/public data) helpful.
- Familiarity with retrieval-augmented generation (RAG) concepts helpful but not required.

## Format

Lecture + scenario walkthrough, 2 hours.

## Lesson plan

Full block-by-block agenda: [docs/timelines.md](docs/timelines.md).

- Microsoft IQ introduction: organizational knowledge, context, relationships, permission-aware intelligence
- Scenario walkthrough: enterprise workflows, contextual intelligence, knowledge-driven AI experiences
- Architecture and readiness considerations: knowledge quality, access boundaries, grounding, freshness, ownership, measurement
- Use case prioritization activity: business value, required context, controls, success metrics

Note: MCP/A2A framework discussions could potentially be folded into this session instead of staying a separate Day 6 — **not yet decided**; this repo keeps them as the dedicated Day 6 closing session pending confirmation.
